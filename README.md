## Selected Work

### Quest-On

**AI assessment SaaS deployed in live university exams**

Quest-On helps instructors create reasoning-based assessments and evaluate student responses through AI-assisted grading workflows.

I lead product engineering across:

- Product architecture and system design
- Full-stack implementation
- Authentication and role-based workflows
- AI evaluation and structured feedback pipelines
- Deployment, monitoring, and live exam operations

**Impact**

- Reduced grading work from approximately **10 hours to 2 hours**
- Achieved an estimated **80% reduction** in grading workload
- Piloted with **2 academic institutions**
- Delivered a production-ready MVP in approximately **3 months**

## Current Project

### ClearBox

**Offline-first, Raspberry Pi-based accident-response AI prototype**

ClearBox is a capstone project that records driving footage and helps users organize important evidence after a vehicle accident.

The system is being designed to:

- Record and manage camera footage locally
- Detect and extract important accident moments
- Track objects using YOLO and ByteTrack
- Build a structured event timeline
- Generate an evidence-oriented report draft

My work focuses on product design, system architecture, camera-analysis workflows, and report-generation scenarios.

`Raspberry Pi 5` · `Python` · `YOLO` · `ByteTrack` · `Picamera2`
